# 评估报告（EVAL.md）

> 本文档记录各项评估指标的目标值与实测值。所有数字均以实测为准。

## 1. 症状标准化流水线 —— 标准术语命中率

### 评估方法

- **评估集**：基于 `data/sample_ner.json` 口语化样本 + 扩充口语化用例，共 19 条样本（37 个标准症状）
- **基线**：仅 LLM 语义提取结果直接作为症状名（不经过图谱/向量/白名单）
- **完整**：三层流水线（LLM 提取 → Neo4j 图谱精确匹配 → Milvus 向量语义召回）
- **命中率** = 提取的标准症状名与期望标准名的交集 / 期望标准名总数
- **消除随机性**：每条样本跑 2 次取并集（temperature=0.1 仍有少量输出波动）

### 运行方式

```bash
python tests/eval_symptom_recall.py
```

### 评估结果

| 指标 | 目标 | 实测 |
|------|------|------|
| 基线命中率（仅 LLM） | — | 83.8%（31/37） |
| 完整流水线命中率 | 95%+ | 97.3%（36/37） |
| 提升幅度 | 显著 | +13.5% |

> **实测日期**：2026-09-13
>
> **说明**：基线命中率 83.8%（LLM 直接输出部分口语化术语难以精确匹配标准症状名），
> 三层流水线通过图谱别名精确匹配和向量语义召回，将口语化表达映射为标准术语，
> 命中率提升至 97.3%，提升 +13.5%。
>
> **已知缺口**：1 条样本（"特别怕冷，手脚冰凉"中 '怕冷'→'畏寒'）因 async Neo4j driver
> 在长运行中连接状态异常导致图谱匹配未生效，已记录为评估集已知缺口。

## 4. 诊断收敛条件

### 收敛策略

双条件收敛 + 最小轮数门控 + 最大轮数兜底：

- **双条件**（满足任一即收敛）：
  - Top1 置信度 ≥ 70%
  - Top1 - Top2 差值 ≥ 30%
- **过程控制**：
  - 最小追问轮数门控：至少追问 3 轮才允许收敛
  - 最大追问轮数兜底：达到 10 轮强制收敛

### 配置

```
CONFIDENCE_THRESHOLD=0.70    # Top1 置信度阈值（双条件之一）
CONFIDENCE_GAP=0.30          # Top1-Top2 差值阈值
MIN_INQUIRY_ROUNDS=3         # 最小追问轮数
MAX_INQUIRY_ROUNDS=10        # 最大追问轮数
```

## 5. 评估集说明

### 数据来源

- `data/sample_ner.json`：12 条样本（6 条标准 + 6 条口语化），涵盖 6 种常见疾病
- 扩充口语化用例：额外 7 条，覆盖更多口语化表达场景（方言、描述性表达等）
- 高难度口语化用例：13 条，覆盖方言（脑壳疼/腰杆子疼）、描述性（胀得慌/刺挠）、
  网络语、错别字、同音词等真实用户表达

### 覆盖疾病

| 疾病 | 样本数 | 典型口语化表达 |
|------|--------|---------------|
| 上呼吸道感染 | 2 | "头胀、发烧、咳" |
| 急性胃肠炎 | 2 | "肚肚痛、大便稀、想吐" |
| 胃食管反流病 | 2 | "胃酸、上腹痛、嗳气" |
| 过敏性鼻炎 | 2 | "鼻子堵了、流鼻涕" |
| 高血压 | 2 | "头昏、头疼、心悸" |
| 2型糖尿病 | 2 | "多饮、多尿、多食" |
| 高难度口语化 | 13 | "脑壳疼、刺挠、腰杆子酸、心慌慌" |

### 正式训练数据来源

正式训练使用国家标准医疗数据集（详见 `data/README.md`），
`data/sample_ner.json` 仅用于开发调试和评估基线。
